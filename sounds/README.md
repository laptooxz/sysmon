Notification sounds are freedesktop system sounds. Create symlinks
in this directory (or your configured SOUND_DIR) pointing at e.g.:

  /usr/share/sounds/freedesktop/stereo/{bell,complete,device-added,
  device-removed,dialog-error,dialog-information,dialog-warning,
  message-new-instant}.oga

Referenced names: bell, complete, device-added, device-removed,
dialog-error, dialog-information, dialog-warning, message-new-instant.
